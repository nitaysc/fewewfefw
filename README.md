# שיחקת אותה! 🎭

משחק הניחושים של החבר'ה — Capacitor app (web code in `www/`, Android wrapper in `android/`).

## Download the APK

Every push builds a new APK automatically. Grab the newest one from
**[Releases → Latest](../../releases/latest)** and tap `shichakta-ota.apk`.

## Project layout

- `www/` — the game itself (`index.html`, `app.js`, `decks.js`, `covers.js`, `style.css`)
- `android/` — native Android project generated by Capacitor
- `.github/workflows/build-apk.yml` — builds the APK and publishes a release

## Build locally

```sh
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```
